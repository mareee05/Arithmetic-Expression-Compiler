# Arithmetic-Expression-Compiler

A simple compiler that translates arithmetic expressions into a textual intermediate representation. The compiler parses arithmetic expressions and generates a readable instruction-like output while supporting integer values up to 6 digits.
Example
Input:12+763*876521
Output:Assign SevHun_SixTen_Thr Mul (EigHun_SevTen_Six)Tou_FivHun_TwoTen_One to t1Assign OneTen_Two Plu t1 to t2Print t2
